# Arcane Ledgers: card data

The card list and the picture of each card, for the Arcane Ledgers card writer app (a phone app that writes the game's NFC cards). The app looks here when it opens and takes anything newer than what it has.

- `cards/manifest.json`: what is current
- `cards/cards.json`: every card and what is written onto its NFC tag
- `cards/faces/`: the printed face of each card

These files are generated; they are not edited here.
